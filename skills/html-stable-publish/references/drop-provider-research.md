# 匿名 HTML Drop 平台核验（2026-08-20）

本参考只保留已核验的、**无需登录或注册即可首次公开上传 HTML/静态产物**的平台。没有一个候选可被官方材料证明为“无需登录且永久保存”；所有链接均应作为即时分享链接交付。

## 可用候选

| 平台 | 可匿名上传的产物 | 无账号链接期限 | 登录后的变化 | 使用结论 |
|---|---|---:|---|---|
| PreviewShip | 单个 HTML、Markdown、PDF，或已构建前端 ZIP | 约 24 小时 | 登录后可保存为项目、延长过期并保留固定 URL | 多文件静态页面/ZIP 的默认匿名候选 |
| HTMLtoURL | 单个 HTML 或粘贴 HTML，最大 20 MB | 默认 3 天 | 付费计划才可恢复/延长同一 URL | 单个 HTML 的最长已核验匿名窗口 |
| EdgeOne Makers Drop（Global） | HTML、目录或 ZIP | 1 小时 | 注册后才会永久保留 | 全球区域的一小时快速分享；中国大陆匿名地址不可用 |
| HtmlSave | 文本型 HTML、CSS、JS、TXT、XML、JSON、Markdown | 24 小时不活跃后会周期性删除 | Premium + 活跃账号才承诺不自动删除 | 轻量原型候选；首页最多 30,000 字符，其他文件最多 15,000 字符 |
| Stacktree | 首个 HTML 发布 | 约 24 小时 | 固定 URL、替换/管理需要账号 | 适合不可猜测 URL 的短期分享 |
| Netlify anonymous deploy | 静态目录 | 临时；1 小时内可认领 | 认领后才能管理 | 仅作 CLI 备用；不能称为持久化 |

## 选择规则

1. **多文件静态网站或 build ZIP**：选 PreviewShip，交付时标注“约 24 小时”。
2. **单个 HTML，且希望匿名窗口尽可能长**：选 HTMLtoURL，交付时标注“默认 3 天”。
3. **只需一小时内快速发给他人**：可选 EdgeOne Makers Drop（仅 Global）或 Netlify anonymous deploy。
4. **需要一个短小原型并愿意用密码保存编辑权**：可选 HtmlSave，但链接仍不能视为长期可靠。
5. **需要不易被猜到的临时地址**：可选 Stacktree，交付时标注“约 24 小时”。

## 明确排除

以下方案需要登录、注册、Token 或账号项目管理，因此不属于本技能：Cloudflare Pages、GitHub Pages、Vercel、Render、Wasmer、Static.app、Tiiny Host、Neocities、Surge、EdgeOne Makers 账号项目。

## 风险与交付要求

- 匿名链接公开可访问，不能上传密钥、个人信息、内网资源或任何不应公开的内容。
- 每次交付都必须同时写平台名、链接类型、预计到期时间和“无账号不可承诺更新/恢复”的边界。
- 服务条款可能变化。发布前再次打开目标平台页面核对有效期；若期限与本参考不一致，以官方页面为准并更新该表。
