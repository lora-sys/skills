# autonomous-run — 无人值守长任务

> **适用**：用户明确要求"跑完再叫我/睡觉前挂着/闲时跑"的长任务。**主导 skill**：无（平台后台能力为主）。

## 步骤

1. **开工前写下两样东西（强制）。** 交付物定义（什么算完成）+ 停止条件（什么情况必须停下等用户：硬边界、阻塞、连续失败）。
2. **拆任务与留痕。** todo 全量列出；每个可逆决策做一行记录（选了什么、为什么），事后可审计。
3. **后台执行长步骤。** 构建、批量生成、多文件改造 → 后台运行；主线程推进不依赖它的步骤。
4. **失败自愈。** 同一问题换思路重试 ≤3 次；三次仍败 → 记录现场，列入"等用户"清单，继续能继续的部分。
5. **只在硬边界停。** 部署、发布、付费、代点发布按钮 → 停下写清楚问题和选项；其余一律自己定。
6. **收尾验收（强制）。** 有具体任务类型时，只执行其 playbook 尚未完成的验收与审查步骤，不重复已跑的质量门或 reviewer；没有专属 playbook 时，按改动风险选择 `../references/web/quality-gates.md` 中相关门，并遵从 SKILL.md 的 M/L 审查档位。
7. **按证据交付。** 交付物清单、决策记录、失败与绕过记录、验收证据。

## 证据形态

决策日志、后台任务输出、验收证据、"等用户"清单。

## 移交

任务本身所属的 playbook（autonomous-run 是执行方式，不是任务类型）。
