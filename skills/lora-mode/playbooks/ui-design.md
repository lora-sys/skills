# ui-design — 设计方向探索、多风格对比、界面评审

> 继承 SKILL.md 七步骨架与硬边界，本文件只写每步的具体动作。
> **适用**：新界面设计、多风格比较、视觉层级与界面评审。**主导 skill**：oil-ui（设计判断不写实现）。

## 步骤

1. **识别现状。** 范围判定：小改直改（记录原因）vs 新界面走全流程；读现有页面、品牌约束、用户偏好。 oil-ui 按需读其视觉/素材/配图/动效参考。
2. **核实事实。** 从真实截图或实际页面出发，不凭想象评审；截图工具用 oil-ui 自带 references/tools.md，不为此另载浏览器类 skill。
3. **出计划。** 设计维度清单（布局、层级、色彩、密度、语气）+ 对比方案数量（默认 2–3）。
4. **方向探索。** oil-ui 产出多风格同屏对比页；并排可比较，不让用户凭文字想象。需要角色/插画素材时调度 lora-visual 或 generate-image，标注"AI 生成"。
5. **用户选定。** 等用户选定方向再继续；不替用户拍板审美决策。
6. **制作与取证。** 按选定方向制作可运行界面或设计稿，实际截图取证；画面上不出现"示例/未接入"等制作说明。
7. **独立评审（强制）。** oil-ui 的独立评审流程（10 分制或不打分两档）；对评审发现做一次减法后再定稿。
8. **按证据交付。** 对比页、选定方案截图、评审结论与减法记录。

## 证据形态

同屏对比页、实际截图（非想象稿）、评审记录、减法前后对照。

## 移交

选定方向要落代码 → `web-feature.md`；已有实现要对齐 → `visual-refinement.md`。
